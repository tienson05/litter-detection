# Scripts Folder Guide

Thư mục `scripts/` dùng để lưu các file code phục vụ những công việc hỗ trợ trong quá trình phát triển và huấn luyện model, chẳng hạn như xử lý hoặc chỉnh sửa dataset.

Một số tác vụ có thể đặt trong thư mục này:
- Chỉnh sửa, làm sạch và chuẩn hóa dataset.
- Chuyển đổi định dạng dữ liệu.
- Chia dataset thành các tập train, validation và test.
- Kiểm tra, thống kê và trực quan hóa dữ liệu.
- Các script hỗ trợ xử lý dữ liệu hoặc tự động hóa công việc khác.

**Lưu ý:**
- Các script nên được đặt tên rõ ràng để dễ hiểu mục đích sử dụng. Và đặt trong thư mục tương ứng của từng người nhé.
- Chỉ lưu code phục vụ các tác vụ hỗ trợ trong thư mục này; code train model được đặt trong `training/train/`.
- Nếu script tạo ra file kết quả, hãy lưu vào thư mục phù hợp thay vì để lẫn với code.

Cứ sử dụng thư mục này cho các script hỗ trợ trong quá trình làm project nhé!
